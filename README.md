# Comprehensive Financial Plan

An illustrative, client-facing wealth management case study built with reproducible Python notebooks. The fictional Rivera household is used to connect cash flow, taxes, retirement income, risk, and estate planning in one recommendation.

## Project roadmap

1. Profile the household and quantify its current balance sheet and annual savings capacity.
2. Model annual retirement cash flows, portfolio withdrawals, and adverse scenarios.
3. Translate the results into an action plan and estate planning checklist.

All figures are hypothetical, in U.S. dollars, and dated to 2026. This is a portfolio demonstration, not individualized financial, tax, or legal advice.

## Reproduce

Use Python 3.11 or later with `jupyter`, `numpy`, `pandas`, and `matplotlib` installed. Run the notebooks in order from the repository root.
